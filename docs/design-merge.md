## 1. DB 변경 없이 옮기는 것

- 첫 화면: 히어로(벨라쌤 사진) → 수강생 바로가기(현장/불라방·강의실·미션·특강·FAQ·소개, 지금 메뉴 그대로) → 경력·소개 → 16회 프로젝트 → 반 찾기(3문제) → 성적 인증·후기 → 혜택 → 강좌 시간표(자동) → 마무리 → FAQ(관리 [FAQ] 내용)
- 머리(로고 VELLA TOEIC · 🔔 · 강의실 · 메뉴 서랍), 바닥글
- 카드·버튼 모양, 나타나기·숫자 세기 움직임('동작 줄이기' 설정이면 끔)
- (2단계) 강의실: 진행 링(n/16회 · 종강 D-n), 휴대폰 아래 메뉴 막대, 3D 아이콘 — 기능은 그대로
- (2단계) 신청서·특강 화면 모양: 반 → 과정 → 시간 고르기 카드, 금액 요약 카드

## 2. 디자인에만 있는 새 기능 (DB 필요 — 정한 뒤 하나씩)

| 기능 | 판단 |
|---|---|
| 숙제 사진 제출 + 쌤 점검·코멘트 | ⚠️ 200명 × 16회 × 사진이면 한 달 수 GB → Supabase 무료(저장 1GB·전송 5GB) 초과. 11월 전송량 초과 이사와 같은 위험. **네이버 카페 유지 추천** |
| LC 음원 회차별 칸(수업일에 열림) | 파일 업로드는 같은 이유로 ✕. 링크 방식 그대로 '회차 칸 + 수업일에 열림'만 가능 (작은 DB 변경) |
| LC 음원 Dropbox 링크 (Vella 제안) | ✅ 가능. DB에는 제목+링크만 저장 → Supabase 용량·전송량 거의 0. 지금도 https 링크면 저장돼요(관리 화면에 '구글 드라이브 링크가 아니에요' 안내만). 할 일: ① Dropbox 링크 `dl=0` → `dl=1` 자동 변환(바로 다운로드) ② 안내 문구 '구글 드라이브 또는 Dropbox' ③ 무료 Dropbox 한도(저장 2GB, 공유 링크 하루 전송량 약 20GB) 확인 — 개강 첫날 200명 × 음원 크기로 계산 |
| 모의고사 성적·목표 그래프 | OMR 채점 프로젝트와 함께 |
| 알림함(쌤 코멘트) | 지금 공지 팝업·🔔로 대부분 됨 |
| 택배 송장번호 + QR 찍기 | 가능 (작은 DB 변경) |
| 숙제 기한 '다음 수업일 17:00' | 지금 규칙(수업일 당일·다음 날) 유지 |

## 3. 그대로 가져오지 않는 것

- 검색 차단(noindex, robots 전체 차단) — 지금 사이트는 네이버·구글 노출이 목표
- 보안 헤더(CSP) 그대로 복사 — 카카오 주소 검색·유튜브가 깨질 수 있음 (필요하면 따로 맞춰서)
- 체험 계정, 예시 학생·점수·숙제 사진(img/hw)
- 틀린 정보: '12월 수업 12/7~12/31'(실제 12/1~12/24), '매주 토요일 적중 특강'(실제 매달 2번, 금 또는 토), '주 5회 과정'(실제 주 4회), '12월 강좌'·'프리미어반 응시권'처럼 달마다 바뀌는 문구 → [수업일 설정]의 개강일로 자동
